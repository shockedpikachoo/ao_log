# ao_log · 알비온 온라인 아시아 서버 킬 기록 수집

알비온 온라인 장비 도감의 장착 순위와 '1:1 참고 순위'에 쓸 새 표본을 모으는 저장소입니다.

## 하는 일

- GitHub Actions가 공식 킬 기록 API(아시아 서버)를 4분마다 확인해 새 기록을 받습니다.
- 받은 기록은 20분마다 `data/` 폴더에 저장되고 자동으로 커밋됩니다.
- 한 번 실행되면 약 5시간 45분 동안 수집하고 끝납니다. 각 실행이 시작할 때 다음 실행을 미리 대기열에 넣고(매시간 17분 예약도 함께 사용), 앞 실행이 끝나는 즉시 이어서 수집합니다.
- 수집 기간은 **2026년 10월 24일 02:00(한국 시간)** 까지입니다. 순위에는 **10월 17–23일(한국 시간) 7일**을 씁니다. 기간이 지나면 실행되어도 바로 끝납니다.

## 저장하는 내용

플레이어 이름, 길드, 플레이어 ID는 저장하지 않습니다.

| 대상 | 항목 |
| --- | --- |
| 모든 기록 | 이벤트 번호(`i`), 시각(`t`, UTC), 가해자 수(`n`), 그룹 인원(`g`) |
| 단독 처치 (`n`·`g`가 모두 1) | 위 항목, 기록 종류(`ty`), 처치 구역(`a`), 가해자 명단이 처치자 한 명인지(`pk`), 그룹 명단이 비었거나 처치자 한 명인지(`gk`), 평균 IP(`ki` 처치자 · `vi` 사망자), 장비 10칸의 아이템 코드(`ke` 처치자 · `ve` 사망자) |

장비 칸 순서: 주무기, 보조 장비, 머리, 몸통, 신발, 가방, 망토, 탈것, 물약, 음식. 빈 칸은 `null`입니다.

수집 상태(읽은 페이지 수, 새 기록 수, 시간 범위, 빈 구간 여부)는 `logs/`에 남습니다. `"gap": true`가 있으면 그 사이 기록 일부를 받지 못했다는 뜻입니다.

## 잘 돌고 있는지 확인하기

- 커밋 목록에 `data: +N events (M solo) ...`가 20분마다 쌓이면 정상입니다.
- **Actions** 탭의 *Collect Asia kill events*에 실행 중 1개와 대기 중 1개가 보이면 정상입니다. 대기하다가 새 예약으로 바뀐 실행은 'cancelled'로 표시되며, 이것도 정상입니다.
- 바로 시작하려면 Actions → *Collect Asia kill events* → **Run workflow**를 누르세요.

## 멈추거나 기간을 늘리기

- 멈추기: Actions → *Collect Asia kill events* → 오른쪽 위 `…` → **Disable workflow**
- 기간 늘리기: `collector/config.json`의 `stopAt`을 원하는 날짜로 바꿉니다. 하루에 약 8MB씩 쌓입니다.
